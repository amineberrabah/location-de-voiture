# 🚗 AutoDrive — Location de Voiture

Site web professionnel de location de voiture destiné au marché algérien.

## ✨ Fonctionnalités

### Site Client
- Flotte de véhicules en temps réel (Firebase)
- Calendrier interactif avec périodes bloquées
- Vérification de disponibilité automatique
- Calculateur de prix instantané
- Filtres par catégorie, boîte, prix
- Bouton WhatsApp flottant
- Page contact + Google Maps
- Conditions de location
- Politique d'annulation

### Dashboard Admin
- Connexion sécurisée via Firebase Auth
- Gestion des réservations (confirmer / annuler / supprimer)
- Détection des conflits en temps réel
- Gestion de la flotte (ajouter / modifier / publier)
- Upload photos via ImgBB
- Statistiques graphiques (Chart.js)
- Notifications sonores nouvelle réservation
- Export CSV
- Accès via URL secrète

## 🛠 Technologies
- HTML / CSS / JavaScript (Vanilla)
- Firebase (Firestore + Authentication)
- ImgBB (stockage images)
- Chart.js (graphiques)
